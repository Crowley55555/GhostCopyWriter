# Принципы

## Черновик

Версия 1 (2026-10-06), принята владельцем. Правила для спорных решений в демо: если функция им противоречит, в MVP она не входит.

1. **Показываем только то, что работает.** В README и на сайте нет непроверенных обещаний. Выключенную функцию убираем из интерфейса, а не оставляем нерабочую кнопку.
2. **Пост звучит как бизнес, а не как нейросеть.** Качество текста важнее числа функций. Штампы вроде «выведите бизнес на новый уровень» — дефект.
3. **Минимум ввода.** Тема и площадка, остальное по умолчанию. Настройки спрятаны.
4. **Минимум затрат и движущихся частей.** Один сервер, один провайдер AI (GigaChat), никаких сервисов «на будущее».
   Исключение (решение владельца 2026-10-07): импорт профиля по ссылке на сайт или сообщество VK (`mvp.md`, п. 4б). Он добавляет обращения к VK API и чужим сайтам, но служит принципу 2: пост звучит как этот бизнес. Провайдер AI остаётся один; при сбое импорта демо работает на ручных полях (принцип 5).
5. **Демо нельзя сломать на показе.** Лимиты на генерации, понятные ошибки, ничего не зависит от Telegram и VPN.
