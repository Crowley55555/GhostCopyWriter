# Образ будущего

Версия 1 (2026-10-06). Горизонт — год, если всё пойдёт хорошо. Каждый этап открывается только при выполнении условия; без него Ghostwriter остаётся демо.

Версия 2 (2026-10-07): у этапа 1 два условия — проверка на себе и проверка спроса; регистрация уже в MVP. Остальное как в версии 1.

Версия 3 (2026-10-07): видео (этап 2) отложено; провайдера оплаты выбрать позже; добавлена оценка реализуемости. Остальное как в версии 2.

Версия 4 (2026-10-07): профиль бизнеса по ссылке переехал с этапа 1 в демо; этап 1 дополнен приёмами из `references.md`, которые владелец подтвердил. Остальное как в версии 3.

### Картинка будущего

Владелица салона раз в неделю скидывает в Ghostwriter фото и короткие видео с телефона и пару слов о новостях. Взамен получает готовые посты и ролик для VK и Max, которые звучат как её салон, а не как нейросеть. Соцсети ведутся за 15 минут в неделю, без SMM-специалиста.

### Этапы

**0. Сейчас — демо** (`mvp.md`). Пост по теме, картинка по кнопке, вход через «Попробовать» или по логину и паролю. Профиль бизнеса и образцы постов можно заполнить по ссылке на сайт или сообщество VK (`mvp.md`, п. 4б; решение владельца 2026-10-07).

**1. SaaS для владельцев бизнеса.**
Условие: прошла проверка на себе (`proof-of-value.md`, «Проверка на себе») **и** проверка спроса подтвердила ценность (`proof-of-value.md`, «В резерве»). Если продукт не годится даже автору, продавать его рано.
- Сервис запоминает бизнес подробнее, чем две строки «О бизнесе» в демо: что продаёт, кому, каким тоном говорит (с учётом 152-ФЗ — `risks.md`). Регистрация по логину и паролю и профиль по ссылке уже есть в MVP.
- Приёмы из `references.md`, подтверждённые владельцем 2026-10-07:
  - сервис учится на правках: исправленный владельцем пост становится образцом (п. 8);
  - календарь поводов: праздники, сезоны, типы постов как готовые темы (п. 11);
  - отдельный тип поста «отзыв клиента → пост» (п. 12);
  - «О бизнесе» тоже можно надиктовать, не только тему (п. 14);
  - пакетный режим «5 тем → 5 постов» и «один пост → все площадки» (п. 10, 30);
  - при автопостинге пост не уходит без одобрения владельца (п. 15); для Max — библиотека `maxapi` (п. 27).
- Пост из материалов владельца: его фото и короткой заметки, а не только из темы.
  Заметку можно надиктовать (так делает ChatPost, `references.md`, п. 6; добавлено 2026-10-07). Распознавание дешёвое: Yandex SpeechKit — 0,1626 ₽ за 15 секунд, около 0,65 ₽ за минуту; SaluteSpeech с 15.07.2026 не продаёт пакеты физлицам. Это второй провайдер ИИ, а принцип 4 для демо его не допускает, поэтому только этап 1. В демо надиктовать тему можно и сейчас, без кода, через диктовку в клавиатуре телефона (гипотеза, проверить на телефоне).
- Оплата на сайте вместо бота. Провайдера выбрать позже: не обязательно ЮKassa, хотя её код уже есть (решение владельца 2026-10-07).
- Публикация в VK и Max в один клик или по расписанию.

**2. Видео** (идея владельца). **Отложено** (решение владельца 2026-10-07): одному разработчику на вайб-коде это сейчас не окупится и не будет работать стабильно (см. «Реализуемость»).
Условие: этап 1 приносит выручку, которая покрывает стоимость генерации видео.
- Склейка видео владельца в один ролик: несколько коротких видео с телефона → клип или длинный ролик с подписями и текстом поста.
- Генерация видео — точечно (заставки, переходы, недостающие кадры). Причины две: это заметно дороже текста, а площадки, по отраслевым данным, лучше показывают живой материал, чем сгенерированный (`deep-research.md`). Стоимость посчитать перед этапом.

**3. Другие модели и новые сегменты** (идея владельца).
- Другие модели — внутри сервиса: под каждую задачу (текст, картинка, видео) берётся лучшая по цене и качеству. Не выбор из списка моделей для пользователя: агрегаторов «150 нейросетей за 220 ₽» уже хватает (`deep-research.md`).
- SMM-специалисты: несколько бизнесов в одном кабинете (отложенный сегмент из `superidea.md`).

### Реализуемость

Оценка 2026-10-07: можно ли собрать это на вайб-коде одному разработчику. Технические факты — со ссылками, проверены 2026-10-07; остальное — оценка.

- **Этап 0, демо — да.** Фазы 0–1 плана закрыты. Импорт по ссылке реализуем: `wall.get` читает открытую стену с сервисным ключом VK, разбор HTML — уже подключённым `beautifulsoup4`. Главная работа — защита от SSRF (`risks.md`, п. 13). Главный риск — качество текста: промпт снижает число штампов, но не гарантирует, что их не будет (Lite — 3 поста из 10). Рычаги: Pro, образцы постов владельца, проверка по стоп-листу с одной повторной генерацией. Безопасность держится на ревью каждой фазы.
- **Этап 1, SaaS — технически да, упрётся не в код.** Пост к фото: GigaChat распознаёт изображения через API. Публикация в VK: `wall.post` требует токен администратора, токеном сообщества нельзя — значит вход через VK и хранение чужих токенов (безопасность, 152-ФЗ). Max: Bot API есть, отложенный постинг уже делает SMMplanner, документации мало. Оплата: нужны самозанятость или ИП и оферта. Узкое место — спрос и привлечение пользователей.
- **Этап 2, видео — пока нет.** Склейка роликов с субтитрами реальна (ffmpeg и Whisper), но «умный» монтаж ненадёжен, а генерация видео и серверы под неё заметно дороже текущего бюджета.
- **Этап 3 — да, вопрос денег.** Выбор модели под задачу технически прост.
- **Никаким кодом не решается:** пост, который звучит как этот бизнес, по двум строкам «О бизнесе» (нужны образцы его постов — с 2026-10-07 их можно взять из сообщества VK); проверка спроса; юридическая часть.

### Что держит курс

Каждая новая функция отвечает на вопрос из ядра: помогает ли она владельцу без навыка писать регулярно публиковать посты, которые звучат как его бизнес? Если нет — она не нужна, даже если её умеют конкуренты.
