Коротко:

- **Штампы.** Штампов из стоп-листа нет ни у одной модели. У Lite два перефраза. У Pro перефразов нет.
- **Выдумки.**
  - Цен, скидок, адресов и акций нет ни у одной модели.
  - У Lite — два обещания, которые промпт прямо запрещает.
  - У Pro — четыре выдуманных факта, среди них отзыв клиента и ссылка на «исследования».
- **Нормы.**
  - Обе модели пишут короче нормы во ВКонтакте и Дзене. Статьи Дзена — 828–1257 знаков при норме 1500–2500.
  - У Lite эмодзи вне нормы в трёх постах. У Pro во ВКонтакте два поста без хэштегов.
  - В Telegram длина в норме у обеих моделей.
- **Скорость.** Pro отвечает в 2,5 раза дольше. Токенов тратит примерно столько же. Цена токена Lite и Pro в этом раунде не проверялась.
- **Как переключить модель:** переменная окружения `GIGACHAT_MODEL`, например `GIGACHAT_MODEL=GigaChat-2-Pro`. По умолчанию — `GigaChat` (Lite).

## Нормы площадок

Значения по умолчанию из формы: `PLATFORM_DEFAULT_SETTINGS`. Числа — из `POST_LENGTH_RANGES`, `HASHTAG_RANGES`, `PLATFORM_EMOJI` в `generator/gigachat_api.py`.

- **ВКонтакте:** 600–1200 знаков, 1–3 хэштега в последней строке, эмодзи 1–3, без `**`.
- **Telegram:** 300–600 знаков, без хэштегов, эмодзи не больше 2, главное — в первой строке. `**` допустим.
- **Дзен:** 1500–2500 знаков, без хэштегов и эмодзи, без `**`. Первая строка — заголовок. Структура: вступление, 2–4 смысловых блока, вывод.

## Как проверялось

- **Путь генерации тот же, что у пользователя.** `GenerationForm` подставляет значения по умолчанию, затем вызывается `generate_text`. Модель задана через `override_settings(GIGACHAT_MODEL=…)`, значение по умолчанию не менялось. Скрипт прогона — в приложении. Ключи он не читает и не выводит.
- **Скриптом посчитаны:**
  - длина — `len(text)`;
  - хэштеги — `#\w+`, все в последней строке;
  - эмодзи — символ с модификаторами и последовательность через ZWJ считаются одним эмодзи;
  - `**` в сыром ответе;
  - штампы — `find_stop_phrases` после исправления ложных срабатываний.
- **Глазами проверены:** перефразы штампов, выдумки по теме и «О бизнесе», первая строка, структура Дзена, манера.
- **Выдумки делятся на три группы:**
  - цены, скидки, адреса, акции;
  - другие явные выдумки: факты, отзывы, исследования, ингредиенты, график, а также обещания, которые промпт прямо запрещает (очереди, польза для здоровья);
  - спорные: общие слова о пользе и качестве, которых нет во вводе. В сводке они не считаются.
- **Постобработка.** Снятие `**` во ВКонтакте и Дзене добавлено после прогона Lite и до прогона Pro. Промпт при этом не менялся: системный промпт и сообщение пользователя сверены для всех 10 тем. Тексты Lite пересчитаны из сырых ответов модели нынешней постобработкой. Сырой ответ отличается от итогового текста только пробелами в конце строк, а в постах Lite 5 и 8 — снятыми `**`.
- **Журнал вызовов** — локальная `db.sqlite3`.
  - 30 строк `TEXT_GENERATION`, id 43–72, 2026-10-07 18:01–18:06 UTC.
  - Строки id 41 и 42 (18:01:01) — пробный запуск скрипта с фейковым клиентом. К GigaChat он не обращался.

"""
Метрики постов прогона против норм площадки: длина, хэштеги, эмодзи, `**`,
первая строка, абзацы, штампы. Нормы — из generator.gigachat_api
(POST_LENGTH_RANGES, HASHTAG_RANGES, PLATFORM_EMOJI) и значений по умолчанию
формы (PLATFORM_DEFAULT_SETTINGS)

Запуск из корня проекта: .venv/Scripts/python.exe metrics.py samples.json [раунд]
"""
import contextlib
import io
import json
import os
import re
import sys

sys.path.insert(0, os.getcwd())
os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'ghostwriter.test_settings')
with contextlib.redirect_stdout(io.StringIO()):
    import django

    django.setup()
    from generator.forms import PLATFORM_DEFAULT_SETTINGS
    from generator.gigachat_api import HASHTAG_RANGES, PLATFORM_EMOJI, POST_LENGTH_RANGES, find_stop_phrases

# Одно эмодзи — символ с модификаторами и последовательность через ZWJ: 🤸‍♀️, ✔️
_EMOJI_CHAR = '[\U0001F000-\U0001FAFF☀-➿⬀-⯿⌀-⏿]'
EMOJI_RE = re.compile(f'{_EMOJI_CHAR}[️\U0001F3FB-\U0001F3FF]*(?:‍{_EMOJI_CHAR}[️\U0001F3FB-\U0001F3FF]*)*')
HASHTAG_RE = re.compile(r'#\w+')


def in_range(value, low, high):
    return value >= low and (high is None or value <= high)


def metrics(post):
    platform, text = post['platform'], post['text']
    defaults = PLATFORM_DEFAULT_SETTINGS[platform]
    length_low, length_high = POST_LENGTH_RANGES[defaults['post_length']]
    tags_low, tags_high = HASHTAG_RANGES[defaults['hashtag_usage']]
    emoji_low, emoji_high = PLATFORM_EMOJI[platform]

    lines = [line for line in text.splitlines() if line.strip()]
    hashtags = HASHTAG_RE.findall(text)
    tags_in_last_line = all(tag in lines[-1] for tag in hashtags) if hashtags else True
    emoji = EMOJI_RE.findall(text)
    paragraphs = [p for p in re.split(r'\n\s*\n', text.strip()) if p.strip()]
    first_line = lines[0] if lines else ''
    result = {
        'length': len(text),
        'length_norm': f'{length_low}–{length_high}',
        'length_ok': in_range(len(text), length_low, length_high),
        'hashtags': len(hashtags),
        'hashtags_norm': f'{tags_low}–{tags_high}' if tags_high else '0',
        'hashtags_ok': in_range(len(hashtags), tags_low, tags_high) and tags_in_last_line,
        'emoji': len(emoji),
        'emoji_norm': f'{emoji_low}–{emoji_high}' if emoji_high else '0',
        'emoji_ok': in_range(len(emoji), emoji_low, emoji_high),
        'bold': text.count('**') // 2,
        'bold_ok': platform == 'Telegram' or '**' not in text,
        'paragraphs': len(paragraphs),
        'first_line': first_line,
        'stop_phrases': find_stop_phrases(text),
    }
    if platform == 'Дзен':
        result['headline_ok'] = (len(first_line) <= 70 and not first_line.endswith('.')
                                 and not EMOJI_RE.search(first_line) and 'заголовок' not in first_line.lower()
                                 and len(paragraphs) > 1 and first_line == paragraphs[0].strip())
    return result


def main():
    path = sys.argv[1]
    round_label = sys.argv[2] if len(sys.argv) > 2 else None
    for post in json.load(open(path, encoding='utf-8')):
        if round_label and post['round'] != round_label:
            continue
        m = metrics(post)
        flags = [name for name in ('length_ok', 'hashtags_ok', 'emoji_ok', 'bold_ok', 'headline_ok')
                 if name in m and not m[name]]
        print(f"{post['round']} {post['number']:>2} {post['platform']:<8} len {m['length']:>4} ({m['length_norm']}) "
              f"# {m['hashtags']} ({m['hashtags_norm']}) emoji {m['emoji']} ({m['emoji_norm']}) ** {m['bold']} "
              f"par {m['paragraphs']} stamps {m['stop_phrases']} нарушения {flags}")
        print('   первая строка:', m['first_line'][:100])


if __name__ == '__main__':
    main()
